# Phx Pause

Shared pause menu for FRUKT mods by [Phoenix557](https://github.com/Phoenix557). Pause the game and open **PHX PAUSE** to see the mods you have installed and change each one's options.

Walking and X-Ray need this installed. They will not show their settings without it.

## Install

1. Install [MelonLoader](https://melonwiki.xyz/#/) on FRUKT if it is not already there. Use the installer and pick `FRUKT.exe`.
2. Close FRUKT. The game locks files in `Mods` while it is running.
3. Download `Phx.dll`.
4. Put `Phx.dll` in the game's `Mods` folder.

Steam's default folder is:

```
C:\Program Files (x86)\Steam\steamapps\common\FRUKT\Mods
```

5. Put any other Phoenix557 mods in that same `Mods` folder. `Phx.dll` has to be there with them.
6. Start FRUKT, pause, and open **PHX PAUSE**.

Settings are saved to `UserData/Phx.cfg` next to the game.

## Update

Close FRUKT, replace `Phx.dll` in `Mods`, and start the game again.
